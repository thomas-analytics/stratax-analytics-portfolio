STRATAX / IMPLEMENTATION GUIDE

Build the Retail Sales Power BI report

Create the native .pbix report from the included cleaned CSV and use these calculations and checks to make the dashboard defensible.

Important: this is a build guide, not a completed Power BI file. The Python charts in this portfolio are previews. Only describe this as a completed Power BI dashboard after you build, check, and save the .pbix report in Power BI Desktop.

1. Load and check data

  1. Open Power BI Desktop → Get data → Text/CSV.
  2. Load project/retail-sales-dashboard/data/processed/retail_sales_clean.csv.
  3. Rename the imported table Sales.
  4. Confirm order_date is Date, quantity is Whole number, discount_pct is Decimal number, and amount columns are numeric.
  5. Check for blank order IDs, negative quantities, and discount values outside 0–1.

2. Add a date table

Date =
ADDCOLUMNS (
    CALENDAR ( MIN ( Sales[order_date] ), MAX ( Sales[order_date] ) ),
    "Year", YEAR ( [Date] ),
    "Month Number", MONTH ( [Date] ),
    "Month", FORMAT ( [Date], "MMM" ),
    "Year-Month", FORMAT ( [Date], "YYYY-MM" )
)

Create a one-to-many relationship from Date[Date] to Sales[order_date]. Sort Date[Month] by Date[Month Number] and mark the date table if available in your Power BI version.

3. Create DAX measures

Gross Sales (PKR) = SUM ( Sales[gross_revenue_pkr] )

Discount Amount (PKR) = SUM ( Sales[discount_amount_pkr] )

Net Revenue (PKR) = SUM ( Sales[net_revenue_pkr] )

Total Cost (PKR) = SUM ( Sales[cost_pkr] )

Total Profit (PKR) = SUM ( Sales[profit_pkr] )

Profit Margin % = DIVIDE ( [Total Profit (PKR)], [Net Revenue (PKR)] )

Total Orders = DISTINCTCOUNT ( Sales[order_id] )

Unique Customers = DISTINCTCOUNT ( Sales[customer_id] )

Units Sold = SUM ( Sales[quantity] )

Average Order Value (PKR) = DIVIDE ( [Net Revenue (PKR)], [Total Orders] )

Discount Rate % = DIVIDE ( [Discount Amount (PKR)], [Gross Sales (PKR)] )

Format amount measures as currency/whole PKR with thousands separators. Format the margin and discount rate measures as percentages. Do not average row-level margins to produce an aggregate margin.

5. Validate before exporting

  • Does total net revenue reconcile to the included KPI summary?
  • Use distinct order count, not row count, for orders.
  • Check Total Profit = Net Revenue − Total Cost.
  • Check Profit Margin = total profit ÷ total net revenue.
  • Confirm monthly labels sort chronologically and slicers filter all relevant visuals.
  • Add a note to the page that this is a synthetic-data portfolio case study.

6. Save and publish artifacts

Save the report as retail-sales-performance.pbix. Export a clean page screenshot or PDF to show in the GitHub README and LinkedIn Project media. Keep the native Power BI file and screenshot in the repository. Do not label the Python-generated preview as a Power BI screenshot.
