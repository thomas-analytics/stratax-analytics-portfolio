## Introductory post (publish after repository has a public URL)

I've been building a practical analytics portfolio through Stratax.

My first case study explores retail sales performance and profitability. I used a reproducible synthetic dataset to work through data cleaning, KPI analysis, SQL queries, and the design of a Power BI dashboard.

The main question is simple: revenue alone doesn't tell the whole story. I wanted to compare sales with profit, margin, discounting, product categories, and channels, then document the analytical process so it can be reproduced.

The data is fictional, and I’m treating this as a learning and demonstration project rather than client work. The repository includes the dataset, Python analysis, SQL queries, findings, and a guide for building the Power BI report.

I'll keep improving it and sharing the work as the portfolio grows.
